# 🇸🇦 السعودية عبر الزمن

موقع تفاعلي يستعرض مناطق المملكة العربية السعودية ومحافظاتها، ويربط الخريطة بقصص ومعلومات كل منطقة عبر خط زمني يمتد من الماضي إلى رؤية 2030.

صُمم المشروع بمناسبة **اليوم الوطني السعودي** ليقدم تجربة بصرية وتفاعلية لاستكشاف المملكة وتاريخ مناطقها.

## المميزات

- خريطة تفاعلية لمناطق المملكة الـ13.
- استكشاف محافظات كل منطقة.
- انتقال وتكبير سلس داخل الخريطة.
- معلومات وقصص مرتبطة بالمنطقة المختارة.
- خط زمني مقسم إلى:
  - الماضي
  - الحاضر
  - ما بعد
  - رؤية 2030
- تصميم متجاوب مع الكمبيوتر والجوال.
- مساعد ذكي مدمج داخل الموقع.
