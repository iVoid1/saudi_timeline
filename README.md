# السعودية عبر الزمن — موقع اليوم الوطني

موقع تفاعلي: خريطة المملكة في المنتصف، تضغط على المنطقة، وتنزل تحت تطلع لك قصتها على خط زمني
(الماضي → الحاضر → ما بعد → رؤية 2030).

## التشغيل

```bash
pnpm install
pnpm dev
```

للنسخة النهائية: `pnpm build` ثم `pnpm preview`.

## وين تحط معلوماتك

كل المحتوى في ملف واحد: **`src/data/regionsContent.js`** — وهو فاضي عمدًا.

```js
riyadh: {
  tagline: 'سطر واحد يظهر تحت اسم المنطقة',
  facts: [
    { label: 'تأسست', value: '١٧٤٤' },
    { label: 'المساحة', value: '٤١٢ ألف كم²' },
  ],
  eras: {
    past:    { text: 'نصّك هنا', highlights: ['نقطة', 'نقطة'], image: '' },
    present: { text: '', highlights: [], image: '' },
    future:  { text: '', highlights: [], image: '' },
    vision:  { text: '', highlights: [], image: '' },
  },
},
```

- أي حقل تتركه فاضي ما يظهر في الصفحة (تشوف مكانه تنبيه أثناء التطوير فقط).
- الصور: حطها في مجلد `public/images/` واكتب المسار `'/images/riyadh-past.jpg'`.
- أسماء المحطات الأربع تغيّرها من `ERAS` في أعلى نفس الملف.
- نصوص المقدمة في الأعلى موجودة في `SITE` في آخر نفس الملف.

## الخريطة

`src/data/regions.js` فيه الثلاث عشرة منطقة كمضلّعات إحداثيات `[خط الطول, دائرة العرض]`،
ويتم إسقاطها إلى SVG داخل `src/components/SaudiMap.jsx`.

- **الألوان**: غيّر `color` لكل منطقة.
- **الشكل**: الحدود مرسومة يدويًا ومبسّطة للاستخدام البصري — ليست حدودًا رسمية.
  لو تبي دقة أعلى استبدل `coords` بملف GeoJSON رسمي (نفس الصيغة: مصفوفة نقاط).
- **المدن**: زد أو احذف من `CITIES`.
- **مواضع الأسماء**: `LABEL_AT` داخل `SaudiMap.jsx` لو اسم منطقة طلع في مكان مو مضبوط.

## البنية

```
src/
  App.jsx                    الصفحة كاملة

  data/regions.js            الحدود والأسماء والألوان
  data/regionsContent.js     ← محتواك أنت
  styles/app.css             التنسيق
```
